# Emotion Detector Final Project

AI-based Emotion Detection web application created for the IBM Python project.

## Features

- Uses the Watson NLP EmotionPredict service
- Detects anger, disgust, fear, joy, and sadness
- Returns the dominant emotion
- Includes a reusable `EmotionDetection` Python package
- Includes unit tests
- Provides a Flask web interface
- Handles blank/invalid input
- Supports static code analysis with PyLint

## Run

```bash
python3.11 server.py
```

Then launch the application on port `5000`.
